# Root Access — Terminal Playground

A standalone ASCII hacking toy by Baylel Games.

**[Play in your browser](https://andthattoo.github.io/root-access-terminal/)**

Type with any regular keyboard key, or hold a key to keep writing fictional code.
Complete a contract, collect its reward, and move automatically to the next job.
The on-screen HACK button works with mouse and touch. Browser shortcuts and Tab
navigation keep their normal behavior.

No installation, account, dependencies or backend. Reloading starts a fresh
session. This prototype is separate from the Root Access Unity game.

## Hosting

GitHub Pages serves the root of `main`. The `.nojekyll` file keeps it a plain
static site. All asset URLs are relative, so it works under this repository's path.
Push updates to `main` to republish.

All code shown in the terminal is fictional visual feedback.
